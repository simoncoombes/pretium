# pretium → tradefloor

This library is now **[tradefloor](https://github.com/simoncoombes/tradefloor)**.
Docs: **https://tradefloor.dev**

Versions published as `pretium` — through 0.4.3 — remain on
[PyPI](https://pypi.org/project/pretium/) and
[crates.io](https://crates.io/crates/pretium) forever: published results
cite those exact versions and they replay bit for bit. New work installs
`tradefloor`.

This repository exists to keep old links resolving and the old name from
being claimed by someone else.
